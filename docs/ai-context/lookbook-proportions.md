# 룩북 체형과 기장 참고

프롬프트·보조 도식·합성 평가를 수정할 때 읽는 선택 문서다. 업로드·작업 복구·이미지 정리는 [이미지와 생성 작업](media-jobs.md)을 따른다.

## 체형·옷 기장 보존

[outfit-preview.service.ts](../../apps/api/src/features/outfit/outfit-preview.service.ts)는 새 생성 시 서버의 최신 신체 프로필과 선택한 옷의 실측·누끼 이미지를 읽는다. 키·체중·체형·어깨·가슴/허리/엉덩이/허벅지 둘레·인심을 전달하고, [lookbook-proportion-guide.ts](../../apps/api/src/features/outfit/lookbook-proportion-guide.ts)는 상세 치수를 일반적인 모델 체형·선호 핏보다 우선한다. `athletic`은 자연스러운 근육형, `broad`는 큰 골격·체격으로 구분하며 체중만으로 근육량·체지방률을 단정하지 않는다. 옷 가슴 단면의 두 배에서 신체 가슴둘레를 뺀 값은 약식 여유 지침이며, 원단·패턴을 반영한 실제 착용 판정은 아니다.

하의는 허리·엉덩이도 각각 `옷 단면 × 2 − 신체 둘레`로 비교해 `nominalWaistEaseCm`·`nominalHipEaseCm`을 전달한다. 측정값이 있는 부위만 계산하며, 여유가 작으면 몸에 가까운 드레이프를, 양의 여유가 크면 허리 주변의 남는 공간과 힙의 원단 여유를 표현하도록 안내한다. 음의 여유를 맞는 옷으로 보이게 하려고 몸을 줄이거나 옷을 키우지 않으며, 참조에 없는 벨트·밴딩을 추가하지 않는다. 원단·신축성·패턴·밑위에 따라 실제 착용감이 달라지므로 절대 cm 기준으로 핏을 확정하지 않고, 신체 허벅지 치수가 없으면 그 값을 새로 추정하지 않는다. 실제 생성 검사는 같은 옷에서 신체 둘레만 바꿔 남는 공간·주름·당김이 달라지는지 확인하고, 숫자 전달 검사를 시각적 핏 검증으로 대신하지 않는다.

계산한 여유와 핏 안내는 체형 지침 바로 다음의 별도 중요 섹션에 두고, 기본적인 보통 핏이나 선호 핏보다 우선하도록 한다. 하의는 부위별 여유를 신체 둘레로 나눈 비율도 전달하고, 음수는 치수 충돌, 0~3%는 가까운 핏, 15% 이상은 넉넉한 핏, 그 사이는 중간 정도의 여유라는 직접적인 시각 지침을 만든다. 이 경계는 생성 그림의 대비를 위한 제품 휴리스틱이며 의류 표준이나 실제 착용 가능 여부를 판정하는 기준이 아니다. 계산하지 못한 부위에 지침을 적용하거나, 힙 여유만으로 허벅지·종아리·밑단까지 좁히지 않는다.

신체 `thighCircumferenceCm`는 한쪽 위 허벅지 둘레이며, 바지 `thighWidthCm`는 한쪽 다리의 허벅지 단면이다. 두 값이 있으면 `바지 단면 × 2 − 신체 둘레`로 `nominalThighEaseCm`·상대 여유·`thighVisualCue`를 계산한다. 예를 들어 신체 70cm와 바지 단면 35cm는 약식 여유 0cm이므로 해당 허벅지 부위에 남는 공간 없이 붙는 표현을 직접 지시한다. 신체 다리를 줄이거나 바지를 키워 맞추지 않으며, 무릎·종아리·밑단까지 임의로 좁히지 않는다. 스커트에는 한쪽 바지 다리 치수를 적용하지 않고, 허벅지 실측 쌍이 없으면 허리·힙 치수에서 대신 추정하지 않는다. 프로필 조회·저장과 새 생성 작업 fingerprint에도 신체 허벅지 값이 포함된다.

상세 치수가 없으면 키·체중·체형으로 전신 실루엣과 대략적인 드레이프를 표현한다. `average`를 선택한 경우에도 키 대비 체중이 크면 몸통과 팔다리의 볼륨이 더 커 보이도록 한다. 예를 들어 160cm·80kg 여성의 기본 프로필에는 같은 키에서 허리가 더 넓고, 3/4 방향에서 복부의 입체감이 드러나며, 위팔과 허벅지에 볼륨이 보이도록 지시한다. 자세·확대·옷 크기를 바꿔 체격 차이처럼 보이게 하지 않는다.

상세 치수가 있으면 입력한 부위마다 해당 값을 우선한다. 허리와 엉덩이 둘레가 둘 다 있으면 두 값의 비율도 전달해 부위별 윤곽을 구분하도록 안내한다. 둘레 비율은 사진에서 보이는 정면 너비 비율로 사용하지 않는다. 키·체중·체형은 전체 체격과 입력이 없는 부위에 계속 반영하며, 부위별 옷 여유는 몸과 옷의 실측이 모두 있을 때 계산한다.

키 대비 체중은 생성용 체격의 근사 보조값으로 쓴다. 비근육형에서 가슴·허리·엉덩이 둘레가 모두 비어 있으면 25 이상에서 더 풍부한 체격을, 30 이상에서 더 분명한 체격 차이를 지시한다. 셋 중 하나라도 있으면 입력이 없는 부위에만 그 볼륨을 적용하며 근육형에는 복부 볼륨을 지정하지 않는다. 신체 치수가 비어 있는 부위의 정확한 둘레나 체지방률은 추정하지 않는다.

상의·중간옷·아우터의 총장은 어깨부터 밑단까지의 길이와 키 대비 비율로 전달한다. 키와 총장만으로 골반·무릎 위치를 확정하지 않는다. 서로 다른 레이어의 실측이 있으면 총장 차이와 같은 어깨선 기준의 상대 길이 비율로 밑단 순서·깊이를 안내한다. 짧은 재킷보다 긴 이너는 자연스럽게 아래로 나오고, 긴 코트 안의 짧은 이너는 코트 아래까지 늘리지 않는다. 실측이 없으면 개별 상품 사진의 픽셀 크기로 옷끼리의 실제 cm를 비교하지 않는다.

앞을 완전히 여는 코트·재킷은 중앙 여밈을 이너 밑단 아래까지 열고, 이너의 자유 밑단이 바지 앞에 내려오도록 지시한다. 자연스러운 가림 허용은 앞을 열 수 없는 겉옷에 적용하며, 허리선·바지 단추를 드러내기 위해 이너를 줄이거나 넣지 않는다. [lookbook-layer-layout.ts](../../apps/api/src/features/outfit/lookbook-layer-layout.ts)는 상의·아우터가 각각 하나이고 중간옷이 없으며 두 총장과 완전 앞여밈 판정이 있을 때만 공통 어깨선·같은 축척의 보조 PNG를 만든다. 이 이미지를 옷 사진 뒤에 추가하되 인체·바지 허리 위치를 추정하지 않고 도식의 선·색·라벨을 최종 이미지에 복사하지 않도록 구분한다. 다중·불명확한 레이어에는 도식을 만들지 않는다. 로컬 렌더링을 마친 뒤 기존 요청 시작 검사를 거쳐 제공자를 호출하며, 추가 AI 요청은 발생하지 않는다.

소매 실측이 있으면 몸판·소매를 같은 비교 축척으로 그려 긴 몸판이 소매 끝보다 아래로 내려오는 참조 관계도 전달한다. 실제 봉제 시작점이 다르므로 숫자 차이를 실제 커프·밑단 간격으로 보장하지 않는다. 키 대비 총장이 긴 상의에는 보통 티셔츠로 줄이지 않도록 긴 기장의 대략적인 인상도 덧붙이지만, 이는 실제 골반·무릎 좌표를 계산한 값이 아니다. 중간옷이 있는 조합에서는 인접한 레이어의 가림을 유지하며 코트 안의 모든 밑단을 동시에 드러내도록 강제하지 않는다. 생성 품질 설정은 기존 `medium`을 유지한다.

생성 결과는 가상 착장 참고 이미지이며 실측 수준의 피팅 보장은 없다. 프로필 변경이 과거 이미지를 바꾸지는 않으며 사용자가 ‘현재 프로필로 다시 만들기’ 또는 ‘다시 만들기’를 선택해야 새 프로필로 생성한다. 관련 단위 검사는 `lookbook-proportion-guide.test.ts`, `lookbook-layer-layout.test.ts`, `outfit-preview.service.test.ts`다. 합성 신체·옷으로 실제 이미지 생성을 확인하는 별도 CLI는 [개발과 검증](development.md#실제-ai-검사)에 있다.

## 합성 평가

[evaluate-lookbook-proportions.ts](../../apps/api/src/cli/evaluate-lookbook-proportions.ts)는 신체·레이어 기장 확인용 합성 평가다. `pnpm --filter @closet/api evaluate:lookbook`은 사용법만 출력하고, `--live`가 있어야 실제 유료 이미지 생성을 실행한다. `--cases=athletic-jacket,slim-jacket,broad-coat`로 케이스를 고르고 `--output=경로`로 결과 폴더를 지정한다. 짧은 재킷·긴 이너의 동일 조합을 근육형/슬림 체형으로 비교하고, 큰 체격 여성의 긴 코트를 별도로 확인한다. 실제 계정·옷장·DB·Cloudflare는 사용하지 않으며 제공자 요청은 실행 전체 최대 3회이고 케이스 실패를 자동 재생성하지 않는다. 결과 PNG·프롬프트·합성 실측·보고서를 남기며 PNG 구조 통과와 체형/기장 시각 검토는 구분한다. 이 소량 샘플로 일반 정확도나 실착 오차를 계산하지 않는다.

코트 안 이너 길이만 바꾸는 대조 검사는 `--cases=broad-coat-short-inner,broad-coat,broad-coat-long-inner`로 선택한다. 같은 165cm 프로필·115cm 코트·바지·나머지 실측을 유지하고 이너 총장만 55/70/85cm로 바꾸며 참조 도안도 같은 축척으로 달라진다. 한 번에 3개 초과 사례는 요청 전에 거절한다. 보고서의 `nominalLengthRatio`는 입력된 총장 비율이며 생성 이미지 정확도 수치가 아니다. 실제 전달한 보조 도식과 입력 이미지 수도 결과에 남겨 프롬프트·실측·결과를 함께 시각 검토한다.

보통 체형의 체중 변화는 `--cases=average-176-70-jacket,average-176-90-jacket,average-176-100-jacket`으로 비교한다. 남성·176cm·`average`·동일한 옷·기본 선호 핏을 유지하고 상세 둘레는 비운 채 체중만 70/90/100kg으로 바꾼다. 몸을 날씬한 모델이나 근육형으로 바꾸는지, 자세·확대·옷 크기 차이만으로 체격이 달라 보이는지 별도로 시각 검토한다.

여성의 키·체중과 상세 치수 차이는 `--cases=female-160-55-basic,female-160-80-basic,female-160-80-measured`로 비교한다. 키 160cm·보통 체형·반팔 티셔츠와 바지를 유지한다. 앞의 두 사례는 상세 치수 없이 55kg과 80kg의 전신 볼륨을 비교한다. 뒤의 두 사례는 80kg을 유지하며 상세 치수 추가에 따른 허리와 엉덩이 윤곽, 바지의 허벅지 여유를 비교한다.
